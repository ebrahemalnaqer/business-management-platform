# Security and Privacy Notes

This project is prepared as a public portfolio showcase.

Before deploying it for real operations:

- Replace all placeholder Calendar IDs with your own authorized calendars.
- Keep production customer data outside the public repository.
- Do not commit API keys, credentials, private spreadsheet IDs, or other secrets.
- Review Google Apps Script permissions before deployment.
- Restrict the deployed web app to the intended users and organization.
- Replace demo/sample records with controlled test data.
